# Keyboard Shortcuts

Netfox keeps the keyboard surface small on purpose — most discovery happens passively, so there's not much you need to trigger by hand. Every shortcut below either switches tools, opens a window, flips an app-wide mode, refreshes the device list, or moves through the releases in the Release Notes window.

<MascotNote side="right" pointing label="Tip">

**Three to start with:** <Kbd>⌘</Kbd> <Kbd>R</Kbd> forces every discovery provider to emit immediately, <Kbd>⌘</Kbd> <Kbd>⇧</Kbd> <Kbd>D</Kbd> masks names, MACs, IPv6 and SSIDs for a screenshot that's safe to share, and <Kbd>⌘</Kbd> <Kbd>?</Kbd> opens these docs.

</MascotNote>

On macOS 27 you can also pull a tool's view down to refresh it, as in Mail. What the pull does depends on the tool: see [Overview → Pull to refresh](/docs/tools/overview#pull-to-refresh).

## Application

<ShortcutsTable shortcuts={[
  { keys: ['⌘', ','], action: 'Open Settings (always lands on the General tab)' },
  { keys: ['⌘', 'W'], action: 'Close the main window' },
  { keys: ['⌘', 'Q'], action: 'Quit Netfox' },
]} />

<Callout type="info">
Closing the main window (<Kbd>⌘</Kbd> <Kbd>W</Kbd>) doesn't quit Netfox — the app stays resident in the [menu bar](/docs/menu-bar), still watching the network. <Kbd>⌘</Kbd> <Kbd>Q</Kbd> (or **Quit Netfox** from the menu bar popover's ⋯ menu) is the way to actually exit.
</Callout>

## Settings window

Opened with <Kbd>⌘</Kbd> <Kbd>,</Kbd>. The arrows at the top go back and forward through the panes you opened, as in System Settings.

<ShortcutsTable shortcuts={[
  { keys: ['⌘', '['], action: 'Back — the pane you were on before this one (View → Back)' },
  { keys: ['⌘', ']'], action: 'Forward — the pane you came back from (View → Forward)' },
  { keys: ['⌘', 'F'], action: 'Search the settings by name (Edit → Search)' },
]} />

## Release Notes window

Opened from **Help → Release Notes…**, or from **Learn More…** on the card that appears after an update.

<ShortcutsTable shortcuts={[
  { keys: ['⌘', '['], action: 'Back — the release you were reading before this one (View → Back)' },
  { keys: ['⌘', ']'], action: 'Forward — the release you came back from (View → Forward)' },
]} />

<Callout type="info">
The menus show each shortcut in your keyboard layout's own keys: on an Italian keyboard **Back** reads <Kbd>⌘</Kbd> <Kbd>ò</Kbd> and **Forward** <Kbd>⌘</Kbd> <Kbd>à</Kbd>.
</Callout>
