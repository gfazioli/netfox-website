Netfox 0.24.1

Release notes

A patch for one problem: Netfox could keep showing a port as open after the service behind it had stopped.

Ports

  • Stale "Open" readings are re-checked. The Ports tab shows the last answer each port gave, kept across relaunches and possibly days old. Opening the tab now asks again every port listed as open once that answer is more than a minute old, and a line above the list says how old the list is. A port that doesn't reply keeps its reading: a silence is not a close, and treating it as one would announce a closure that never happened.
  • Full Scan corrects what it finds. It used to record only the ports it found open, so a port listed as open and since closed stayed "Open" after a scan that had just found it closed. It now reports the current answer for every port the tab already shows, and Probe Ports asks those ports too.

Local Services

  • The list keeps itself current. It was read once, when you opened the tab. It now refreshes every few seconds while its window is in front, and stops while it isn't.
