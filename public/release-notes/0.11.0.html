Netfox 0.11.0

Release notes

Netfox now speaks your language 🌍

The entire app is now localized and follows your Mac's system language automatically — there's no setting to flip.

New languages: 🇮🇹 Italian · 🇫🇷 French · 🇩🇪 German · 🇪🇸 Spanish (alongside English)

Localized end to end:

  • Every screen — Overview, Wi-Fi, Devices, Security, Optimization, and the full Settings window
  • Device identities, security findings, Wi-Fi details, alerts, and the activity timeline
  • The menu bar popover and the notch HUD
  • Even the macOS system permission prompts

Also in this release:

  • Notch HUD, focused — the quick device list now shows only the devices that are currently online, keeping the at-a-glance view uncluttered

If your Mac's language is set to one of the new ones, you'll see Netfox in it the moment you update.
