Netfox 0.21.0

Release notes

0.21.0 asks a question about file sharing that most tools do not, and stops the landing screen from quietly costing you a processor.

Security

  • Which version of file sharing a device speaks, and whether it still accepts the retired one. Port 445 gains a check in the port inspector that asks two questions rather than one: the version your Mac and that device would actually negotiate, and — separately — whether the device still accepts the version withdrawn in 2017. They have to be separate, because a device speaking only the old one does not answer a modern request at all, so a single check would report it as nothing rather than as the thing worth knowing. A version with no encryption to offer is named as such, and a reply that settled nothing is no longer reported as a refusal.

Performance

  • The Overview no longer keeps a processor busy while you look at it. Its radar animated without end, redrawing the whole screen sixty times a second whether or not anything had moved — measured at 9.6% of a processor on that screen against 0.6% on any other. It now runs its sweep and stops.
  • The menus stop rebuilding themselves. What sits behind the menu bar is now compared before being republished, so a network that has not changed no longer causes work.

Privacy

  • An opt-out that was not being obeyed. The Overview builds its link panel three ways depending on how wide the window is, and the arrangement the default size lands in skipped the guard — so with the outbound lookup switched off, that panel still reached outside your network. The two arrangements that were correct are the rare ones, which is why it lasted.

Languages

  • Three things were showing English to people who do not read it: the Ports tab described every service in English, the Settings search showed a setting's name in English beside its own translated section heading, and a port number was formatted as though it were a quantity — port 8,080 in English, 8.080 in German and Dutch, 8 080 in French. All fixed in all six languages, with a check that now looks for the whole class of mistake rather than for the instances somebody remembered.

Fixes

  • The explanatory (i) beside a figure is legible again.
