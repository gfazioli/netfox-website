Netfox 0.16.3

Release notes

A fix for Local Services, reported from a machine running a real web server.

Fixed

One row per service, not one per process. A server that runs several worker processes — nginx, and anything else that pre-forks — was listed once for every worker. On a Mac running nginx across three ports that meant 39 entries for about four services: ten identical rows on port 60, ten on 80, ten on 443.

They now collapse into a single row per listener, which says how many processes are behind it. That is the honest summary: the master opens the socket and the workers inherit it, so from the network's side there is one thing listening on port 80, held by ten processes.

Listeners that genuinely differ still get their own row — the same server on another port, or on another address.

Under the hood

  • The listener is now identified by name, port and reachability rather than by process id. The process id shown is the lowest, which for a pre-forking server is the master rather than whichever worker the system happened to report first.
  • Process ids and process counts are rendered without locale digit grouping. A localized number format was turning a five-digit process id into 55.207 on an Italian Mac — the same problem that once affected the port column.

Install

Download the DMG, drag Netfox to Applications. Existing installs update themselves.

Requirements

macOS 15.6 or later. Universal (Apple Silicon + Intel). Signed and notarized.
