Netfox 0.2.0

Release notes

Netfox 0.2.0 — first public release.

A native macOS network monitor that tells you which devices are on your home network and which of them might need a closer look. No account. No cloud. No telemetry.

🔍 Know your network

  • Live device discovery — Netfox combines passive announcement listening, the system's ARP cache, and a periodic gentle ping sweep so even the quiet IoT devices (printers, NAS units, smart plugs) show up alongside the chatty ones.
  • Per-device history — every "came online", "went offline", IPv4 change, and hostname rename is recorded in a timeline that survives across launches.
  • Custom names + kinds — right-click any device → Add Tag to give it a friendly name and the right icon. Tags persist across launches and apply everywhere in the UI.
  • New-device alerts — bell badge + macOS notification when an unknown device joins your network. Configurable threshold for the "device returned after long absence" path.

🛡 Security at a glance

The big new theme in 0.2:

  • Probe Ports — right-click any LAN device → walks a curated catalog of well-known service ports over TCP. No raw sockets, no SYN scans — sandbox-clean, App-Store-compatible. Results land in the new Ports & Services tab on the detail panel.
  • Risk Badge — every device gets a colour-coded shield: green / yellow / red, or grey "Not scanned". Pulsing red shields for the urgent cases, quiet green ones for everything healthy.
  • Risk Inspector — click a badge to open a plain-English breakdown: "Telnet exposed", "Database reachable on LAN", "HTTP without HTTPS". Aimed at home users, no jargon dump.
  • Live findings: Telnet exposed (high) · FTP exposed (high) · Database ports open on LAN (high) · HTTP without HTTPS (medium) · Remote Desktop reachable (medium). Closed and filtered ports stay quiet.

🌐 Public IP banner

The sidebar now reads the network's public-facing IPv4 at a glance — the first question a network monitor should answer ("what face do I show the internet?"). Refresh + copy from the banner. Privacy-conscious: opt-out from Settings → Privacy.

🎬 Demo Mode (⌘⇧D)

Screenshot-safe mode for sharing your screen without leaking personal data:

  • Device names → "Computer #1", "Phone #2", …
  • MAC addresses → last three octets masked
  • IPv6 → keep first hextet, mask the rest
  • Public IP → class-E placeholder (254.253.252.251)
  • Engine IDs hidden, absolute timestamps suppressed
  • Sub-toggle "Include sample data" generates a realistic-looking demo population so the Ports tab + Risk Inspector + bell inbox all read as populated even when nothing's been scanned yet.

🧹 Privacy & Storage

Dedicated Settings tab. One-click wipe for each of Netfox's local stores:

  • Clear Port History
  • Clear Activity History
  • Clear Alert History
  • Clear Custom Tags
  • Forget All Devices (the nuclear option)

Every action requires confirmation. Nothing leaves your Mac, ever.

🎨 Sidebar polish

  • Tier-based device sort: This Mac first, then HIGH-risk, then MEDIUM-risk / has-alert, then the rest, then offline. Animated reorders when state changes.
  • Public IP banner with copy + refresh.
  • Connection icons (Wi-Fi / Ethernet) inline on every row.
  • Top + bottom safe insets so the list doesn't butt up against the chrome.

Under the hood

  • macOS 15+ deployment target, SwiftUI + @Observable.
  • NetfoxCore framework split: discovery providers, security rules, port probe, public-IP service, SwiftData stores — all unit-tested.
  • Auto-updates via Sparkle 2, signed with Developer ID + notarized.
  • 100% native, no Electron, no web views, no cloud.

Free. Requires macOS 15 Sequoia or later.
