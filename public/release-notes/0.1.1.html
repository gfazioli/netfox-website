Netfox 0.1.1

Release notes

A polish release on top of 0.1.0 — three menu items and a settings tab that make the auto-update flow visible, plus a friendlier About panel now that the website is live.

Auto-updates are now real

  • Check for Updates… A new menu item in the Netfox menu (next to About Netfox) opens the update prompt straight away. Useful when you want to confirm you're on the latest build without waiting.
  • Updates settings. Settings (⌘,) gains a new Updates tab with three controls: Check for updates on launch (a silent background check when Netfox starts; off by default), Automatically check for updates (the every-24-hours scheduled check; on by default), and a Check for Updates Now… button that mirrors the menu item.
  • Background updates. When a newer version of Netfox is published, the app surfaces a small prompt so you can update in place. Manual download from netfox.app still works the same way it always has.

About panel, opened up

  • The About panel (Netfox → About Netfox) now links to the public site:
    • Website opens netfox.app.
    • Release Notes opens the changelog page at netfox.app/docs/release-notes.
    • Report an Issue takes you to a pre-filled GitHub issue form.
  • The "Made with ❤️ by Undolog" credit now opens the Undolog studio page instead of a bare GitHub profile.

Help menu

  • The system Help menu is replaced with a single Netfox Help item bound to ⌘? that opens the live documentation at netfox.app/docs. Always in sync with the version you're running.

Compatibility

  • macOS 15 (Sequoia) or newer.
  • Universal binary — native on Apple Silicon and Intel Macs.
  • Signed with Apple Developer ID and notarized by Apple.

Notes for testers on 0.1.0

  • 0.1.0 didn't ship the auto-update channel, so the build won't pick this up automatically — grab the new DMG once and from 0.1.1 onward you'll be offered new versions in-app.
  • Some routers and IoT devices may still show up as "Unknown" or with a generic vendor name. Right-click → Edit tag… to give them a friendlier name.
