Netfox 0.12.0

Release notes

Look inside any open port 🔍

Netfox already told you which ports were open. Now you can see what's actually answering — read-only, all on your Mac.

🔍 Service inspector

Tap any open port for a detail sheet: the recognised product, its live state, and — on demand — a read-only peek at what the service announces (an FTP or mail greeting, a database handshake, an SSH identification line).

🌐 In-app web viewer

For web ports, open the device's own web interface inside Netfox: a resizable viewer locked to that single device — the page works normally, nothing is stored, and it can't wander to the rest of your network or out to the internet.

🔓 Security posture, in plain English

Netfox now reads how safely a service is exposed. The headline: a database reachable with no password is flagged — and that verdict feeds the Risk report, so an exposed dev database shows up as High risk on sight. Flip on Inspect automatically during scans and it's caught as part of a normal sweep.

🚪 Open with the right app

One-click hand-off to the tool your Mac already has: Terminal for SSH, Finder for SMB/AFP/FTP, Screen Sharing for VNC, Remote Desktop for RDP, or a copied connection string for MySQL/PostgreSQL/Redis/MongoDB. Netfox never logs in for you — it just opens the door.

🩹 Steadier device identity

Fixed a case where a device could be shown as the wrong one after your router reshuffled IP addresses. Identity now follows the hardware, so a device keeps its name even when its address changes.

🌍 Localization

The whole inspector is available in English, Italian, French, German, Spanish, Portuguese, and Dutch.

Privacy — Live inspection is off by default and strictly read-only: Netfox opens an outgoing connection only when you ask (or during a scan you started), never sends a password or a command, and is fully suppressed in Demo Mode.
