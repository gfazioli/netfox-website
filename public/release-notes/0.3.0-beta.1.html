Netfox 0.3.0-beta.1

Release notes

Netfox 0.3.0 — modular toolbox, Wi-Fi scanner, network-wide security dashboard.

The shell got rebuilt around five tools, a brand-new Wi-Fi scanner joined the party, the Security tab grew into a real network-wide dashboard, and the Probe-Ports flow now runs on a schedule if you want it to. Same no-account / no-cloud / no-telemetry promise.

🧰 The new shell

Netfox now opens onto a left tool sidebar with five destinations:

  • Home — landing dashboard with at-a-glance KPI cards (Devices · Risk posture · Public IP · Alerts) and a hero Run Smart Scan button that kicks off a network-wide port probe.
  • Wi-Fi — the new Wi-Fi network scanner (see below).
  • Overview — the device list + detail panel you already know, untouched.
  • Security — the network-wide risk dashboard (see below).
  • Optimization — roadmap placeholder for Bandwidth, Link diagnostics, and Speed test.

Switch tools with the sidebar, with ⌘1 / ⌘2 / ⌘3 / ⌘4 / ⌘5, or by clicking any KPI card on Home. The last-selected tool is remembered across launches.

The toolbar also got a refresh: the Netfox brand lockup anchors the leading side, the status filter (All · Online · Offline) and the device search live in the title bar instead of the sidebar so the device list gets its full vertical room back, and the window's native title is suppressed so nothing else fights for the row.

📡 Wi-Fi scanner

A whole new tool dedicated to the airwaves around your Mac. Open Wi-Fi to see every network the radio can hear, not just the one you're on:

  • Live list with traffic-light security + signal indicators. Each row leads with a coloured lock (green = WPA2/WPA3, yellow = older WPA / WEP, red = open) and a coloured wifi icon (green = excellent, red = weak). The colour code is documented in a legend strip at the bottom of the sidebar.
  • Connected network pinned on top. Your network never moves with the sort — sort and filter shape the rest of the list around it.
  • Sort by Signal Strength · Network Name · Channel · Security Type, ascending or descending. Footer-aligned right next to the picker.
  • "All Networks" toggle filters to the same band as your network when you want to compare neighbours on 2.4 vs 5 GHz.
  • Per-network detail panel with a live signal chart (hover for the exact tick + dBm readout below), every advertised AP field (SSID, BSSID, channel, band, channel width, security, country, beacon interval, network type, PHY modes), an info icon next to each field that explains what it means, an inline copy button for every value, and an Export network data action that drops a pretty-printed JSON file with the network + its full sample history.
  • One-click jump from your network's detail panel back to View Devices in Overview — same network, different angle.

First-time use prompts for Location Services access (macOS requires it for any app reading nearby SSIDs + BSSIDs). Data never leaves your Mac.

🛡 Network-wide Security tool

Click Security to see the whole network at a glance:

  • Headline counts ("3 devices need your attention") + summary pills (high · medium · low · untested), all using the same colour language as the per-device Risk Badge.
  • Scan All Devices primary action — kicks off a port probe across every device that hasn't been scanned yet. Rate-limited under the hood (no router floods).
  • Three sections, only rendered when non-empty: High risk · Medium risk · Untested. Each row shows the device name + the first finding ("Port 80 · HTTP without HTTPS").
  • Click any row → jumps straight to Overview with the device preselected AND its Ports tab already active. The flagged port carries an inline risk symbol next to it.
  • After everything's been scanned, the primary action flips to Rescan All Devices so a periodic re-check stays one click away.

Empty states branch on what's actually true: "Nothing to assess yet" when there are no devices, "Everything looks good" when devices are scanned and clean, "Nothing assessed yet" when devices are present but unreachable from this network.

⏱ Scheduled port probing (opt-in)

Settings → Security → Auto-probe ports on a schedule. Off by default. Once on, Netfox re-runs a port scan on every scannable device every N hours (slider: 1 hour … 1 week, default every 6 hours). Same rate limits, same LAN-only enforcement — the schedule can't flood the network. Flipping the toggle starts/stops the sweep immediately.

Security settings now live in their own dedicated Security tab inside the Settings window, separate from Advanced.

🏠 Home dashboard

The new landing tool gives you the network's posture in one screen:

  • Hero card with the current risk headline + Run Smart Scan that cascades a port probe across the LAN and jumps to Security so you can watch the results land.
  • Four KPI cards in a grid:
    • Devices (total · online)
    • Risk posture (high / medium counts, click to jump to Security)
    • Public IP (the displayed value, refresh in place)
    • Alerts (count of unread session inbox, click to open)
  • Roadmap teaser at the bottom — Bandwidth, Wi-Fi diagnostics, Link diagnostics, Speed test, each with version pins.

Demo Mode + sample data populates every card with realistic numbers, so screenshots tell the story end-to-end.

🧭 Optimization placeholder

The Optimization tool reads as a deliberate "coming soon" surface with the upcoming modules laid out (Bandwidth v0.4 · Link diagnostics v0.5 · Speed test backlog) and a link to the full roadmap on the website. Each future module ships when it's ready instead of waiting on the slowest one.

🪟 Window improvements

  • Single-window by design. "Show Tab Bar / Show All Tabs / Merge All Windows" removed — Netfox's model is a singleton, two tabs of the same data would just confuse.
  • Persisted last-section. Quit and relaunch lands you back where you were.
  • Selection survives tool switches. Picking a device in Overview, going to Security, and coming back keeps the device selected.

🐛 Fixes worth calling out

  • Device-detail panel no longer truncates the name or wraps IPv6 mid-octet during window resize.
  • Scan All / Probe buttons now show a live spinner and "Scanning…" label so a click never feels like a no-op.
  • Demo Mode no longer hides every scannable device behind sample data — the Scan All flow now works correctly when demo + sample data are both on.
  • Native macOS Picker(.segmented) and .searchable replace the earlier custom controls in the toolbar so the whole row reads as one visual language.
  • New --prerelease flag on the release pipeline for internal beta cuts that skip the auto-update + homepage promotion.

Under the hood

  • macOS 15+, SwiftUI + @Observable.
  • NetfoxCore continues to host the discovery providers, security rules engine, port probe, Wi-Fi scanner, and SwiftData stores — all unit-tested.
  • Auto-updates via the same EdDSA-signed appcast as v0.2; signed with Developer ID + notarized.
  • 100% native. No Electron, no web views, no cloud.

Free. Requires macOS 15 Sequoia or later.
