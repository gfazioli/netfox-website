Netfox 0.16.5

Release notes

One fix, found while re-verifying a reported issue that turned out to be something else entirely.

Fixed

Netfox no longer runs twice. A second copy of the app left two processes working against the same device history, each with its own view of it. They interfered with each other — and on 0.16.4 they brought each other down within a minute.

Opening Netfox again now brings the copy that is already running to the front, and the second one steps aside before it touches any data.

This also turned out to be the real cause of a reported problem where the main window "could not be reopened": there were two copies running, and the window belonged to the other one.

Under the hood

The check runs as the very first thing at startup, ahead of the code that opens the stored history — arriving any later would leave exactly the race it exists to prevent, which is what brought the app down on 0.16.1 when two copies set up their storage at the same instant.

Which copy stays is decided by a total ordering, so every process independently reaches the same answer: the oldest one. Simply deferring to "whichever other copy I can see" would make two copies launched together each yield to the other and both quit, leaving nothing running at all — the regression test for that fails against such a version with zero survivors, which is how it was verified rather than assumed.

The screenshot tooling that created the situation now closes every copy before it starts, and verifies which build actually launched.

Install

Download the DMG, drag Netfox to Applications. Existing installs update themselves.

Requirements

macOS 15.6 or later. Universal (Apple Silicon + Intel). Signed and notarized.
