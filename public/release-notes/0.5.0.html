Netfox 0.5.0

Release notes

Netfox 0.5.0 makes the menu bar the place your network lives — live traffic, an adaptive icon, always-fresh data — and lets the Security scanner check the ports you care about.

🔍 Custom ports

The port scanner has always walked a curated catalog of well-known ports. Now you can extend it: add your own TCP ports in Settings → Security → Custom ports, with optional labels (9281 = Next.js dev), and every scan — manual or scheduled — checks them too. Your labels show up everywhere: the device detail panel (in their own "Custom" section), the Services view, and alerts. Invalid entries are simply ignored, with a live caption confirming what registered. Changes apply from the next scan, no restart.

📈 Live traffic in the menu bar

The popover now charts your Mac's network throughput over the last minute — download as a filled curve, upload as a line, with live readouts. Sampling runs for the whole life of the app, so the chart opens already filled with history. No special permissions needed.

🦊 Pick your menu bar icon

A new monochrome fox glyph is now the default menu bar mark — it adapts to light and dark menu bars and inverts correctly when the popover is open, like the system's own status icons. Prefer the colour fox? Switch back in Settings → General → Appearance; the change applies instantly.

⚡ Always-fresh popover

Device discovery now starts with the app and runs for its whole life — not just while a window is open. With the main window closed for days, the popover still shows the network as it is right now. The Public IP card also gained a one-click copy button.

❤️ About + Support

A new About + Support window brings together the version info, quick links (website, documentation, release notes, issue reporting), the project's sponsors, and other apps from the same developer. It opens from the app menu, Settings → About, or at launch — with a one-click opt-out if you'd rather it didn't.

🗺 Roadmap note

This release shipped ahead of the planned Wi-Fi diagnostics work, so the module wave shifts by one: Wi-Fi diagnostics is now planned for v0.6, link diagnostics for v0.7, and the bandwidth monitor for v0.8. The roadmap reflects the new order.
