Netfox 0.23.1

Release notes

A fix to the sweep menu that 0.23.0 introduced, reported within hours of it shipping.

One row per network, named the way macOS names it

On a Mac with a cable and a radio on the same network, the menu listed two identical address ranges — en0: 192.168.1.1 – 192.168.1.254 and en1: 192.168.1.1 – 192.168.1.254 — told apart only by a name you would only recognise from a terminal.

They did exactly the same thing. Both ask the same 254 addresses, and the interface makes no difference to which of them answer. So it was a choice with no consequence, offered in a vocabulary nobody uses.

There is now one row per network, and it carries the name macOS itself gives the interface: Ethernet, Wi-Fi, Thunderbolt Bridge, in your own language. Where two networks genuinely differ — a VPN, a second LAN — they stay two rows, as they should.

Documentation

The Devices page now covers two things it never did: the System row, which names the operating system a device states about itself and is deliberately absent rather than approximate when it cannot be translated with certainty; and the rule that opening a device from a search or an alert shows it to you even when a filter would otherwise hide it.
