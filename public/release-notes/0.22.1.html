Netfox 0.22.1

Release notes

A patch for one thing: every Mac running macOS 27 had quietly lost the row that says which system it runs.

Fixes

  • A Mac on macOS 27 shows its system again. Netfox names a device's operating system from a number the device states about itself, and the table that turns that number into a name stopped one release short — so every Mac that had updated lost that row. Absent rather than wrong, which is exactly why it went unreported: a missing row looks identical to a device that chose not to answer.
  • The cause is worth a line, because it is the kind that arrives on its own. The number a Mac states follows a different count from the one this table was built around. The two agreed for every release the table covers and stopped agreeing this year, so the old reading fitted the data right up until it did not — and the row went missing on the day the new system shipped, not on the day anything here changed.

Under the hood

  • There is now a check that asks the Mac it is running on whether Netfox can name its system. The previous guard compared against numbers written into the test itself, so it stayed green on a machine the table had never heard of — which is precisely the state that hid the row. The next time the count diverges, it is a failure somebody sees.

Nothing else in the app behaves differently in this release.
