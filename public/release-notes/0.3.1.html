Netfox 0.3.1

Release notes

What's new

A redesigned Overview

The landing surface has a new identity. The Netfox brand moves from the toolbar into the view itself — a large, centred app mark anchoring the page — and an ambient radar fan pulses softly behind the dashboard. The toolbar is now strictly for commands.

Cleaner card layout

The "At a glance" cards equalise their height so the row reads as a grid instead of a staircase, regardless of how long the secondary copy on each card turns out to be.

Predictable open state

The app no longer remembers which section was last selected. Every time you open Netfox, you land on Overview. Same idea in Settings: ⌘, always opens on the General tab now, no matter where you were the last time you closed the window.

Settings tab order

Tabs reordered so the network-facing ones come first and housekeeping moves to the right edge:

General · Alerts · Security · Privacy · Advanced · Updates · About

Roadmap, refreshed

The Optimization tool's planned modules are re-pinned for the post-0.3 plan:

  • Wi-Fi diagnostics — v0.4
  • Link diagnostics — v0.5
  • Bandwidth monitor — v0.6
  • Speed test — backlog

The See the full roadmap link now opens a dedicated Roadmap page on the documentation site, with more context on what's coming after v0.6.

Accessibility

The radar background respects Reduce Motion — when enabled in System Settings, the animation collapses to a static arc so the page stays still.
