Netfox 0.13.0

Release notes

What's new

A security fix worth applying, and the viewer finally lets you type where you want to go.

The metrics endpoint can no longer be left wide open

If you had switched on Allow access from other devices for the metrics endpoint without setting an access token, that endpoint was reachable from anywhere on your network with no authentication — and what it serves is your whole device inventory: every IP, MAC address, hostname and open port.

Netfox now refuses to start it. Turn on network access without a token and the endpoint stays down, with the reason shown right under Endpoint in Settings → Integrations. A localhost-only endpoint is unaffected and still needs no token — that's the default nearly everyone runs.

If you use this endpoint on your network, set a token after updating and it will start again.

Your access token is treated like a secret

The token now lives in your keychain instead of your preferences file, and the field hides it as you type — so it no longer shows up on screen during a demo or a screen share. An existing token is moved across automatically the first time you launch 0.13.0; you don't need to re-enter it.

Type your way around a device

The built-in web viewer's address bar is editable. Jump straight to /admin, try another port with 192.168.1.9:9000, or switch between http and https — no more closing the window and starting over just to reach a different page.

The host stays locked to the device you're inspecting. That's the whole point of the viewer, so it isn't editable: type a different address and Netfox tells you it's locked here rather than following you there. Changing the port re-points the lock instead of loosening it, and keeps your current path.

Under the hood

  • The endpoint's bearer token is compared in constant time, so response timing no longer hints at how much of a guess was right.
  • Carriage returns are escaped in exported label values, alongside newlines.
  • A single command now runs the test suite, so every change ships against the same gate.
