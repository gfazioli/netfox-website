Netfox 0.16.1

Release notes

A translation fix for the Ports tab.

Fixed

  • The port state badges were English in every language. The Open / Closed / Filtered label beside each port — in the Ports list and in a port's own detail sheet — was never passed through the translation layer, so it stayed English while everything around it was translated. It now reads in your language in all six.

If you use Netfox in English, nothing changes for you. If you use it in Italian, French, German, Spanish, Portuguese or Dutch, the badges join the rest of the interface.

Under the hood

The four states now carry their own translation keys rather than reusing the existing "Open" used for an unencrypted Wi-Fi network. That reuse would have been invisible in most languages and wrong in Spanish, where a network is feminine (una red abierta) and a port is masculine (un puerto abierto) — the shared key would have carried the wrong agreement onto the badge.

Install

Download the DMG, drag Netfox to Applications. Existing installs update themselves.

Requirements

macOS 15.6 or later. Universal (Apple Silicon + Intel). Signed and notarized.
