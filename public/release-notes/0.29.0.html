Netfox 0.29.0

Release notes

Netfox 0.29.0 lets you act on what the Wi-Fi tool shows: join a network from it, and see when a network your Mac already knows is the better one where you are.

Wi-Fi

  • Join a network from Netfox. Select it and choose Join…, or right-click it in the list. A sheet says which network your Mac will leave, warns you when a network is open, and asks for the password, which Netfox hands to macOS for that one join and never keeps. If the join fails, it says why in plain words: the password wasn't accepted, the network is out of range, or macOS didn't allow the change.
  • A stronger network, when it matters. When your Wi-Fi has a problem, the verdict card names a network your Mac already knows whose signal is clearly stronger where you are, with both readings and a Switch… button. Nothing is suggested while your Wi-Fi looks fine.
  • Known networks are marked in the list.
  • The list works like Devices. A filter in the toolbar (only your band, known, or no password), a search (⌘F) that finds a network by name, address, maker or security, a count that says what a filter leaves, arrow keys, a right-click menu, and a width you can drag. A header above the list names the network you're on.
  • ⌘R scans for networks while Wi-Fi is in front; elsewhere it still refreshes the devices.
