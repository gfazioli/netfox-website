Netfox 0.22.0

Release notes

Netfox now works at whatever size you give its window, and below a threshold it stops being a shrunken page and becomes a widget — every figure that matters on screen at once, nothing to scroll, nothing overlapping.

The window is habitable at any size

  • The floor drops from 960 × 560 to 500 × 340, so tiling Netfox into a third or a quarter of the screen no longer cuts its right-hand edge off.
  • It rearranges rather than squeezes on the way down. Six shapes, chosen from the window's measured width and height, each with a renderer of its own.
  • The tool sidebar retracts below 720 points, where it stops paying for itself — 44% of a quarter-width window on a 16-inch display. Nothing is lost: the five tools keep their View menu entries and ⌘1–⌘5, and the toolbar button brings the sidebar back at any size.
  • Window → Default Size puts an over-shrunk window back without dragging a corner.

Each tool has a widget

  • Overview — the summary cards, filled to the height they are given.
  • Devices — what needs attention first, and only as many rows as genuinely fit, with the rest counted.
  • Wi-Fi — the network you are on, then the strongest one near you.
  • Security — the risk tally rather than the list.

Row counts are arithmetic, not a guess: a shared budget decides how many rows a widget can draw and how many it has to count instead, with the invariant that shown + hidden = total.

One pane at a time where two do not fit

  • Devices and Wi-Fi show a single pane below the threshold, with an All devices / All networks link back. Previously a 380-point list and a detail needing 420 could not coexist below about 800 points, and both ended up unreadable.
  • Opening a device or a network is now something only you do. A scan finishing in the background could push a detail panel in front of you that you never asked for.
  • If the network or device you had opened disappears, the list is handed back rather than the pane silently re-pointing at something else.

Fixes and details

  • The sponsor capsules compressed their labels instead of restacking when the sidebar narrowed.
  • The Overview performed two geometry writes on every layout pass.
  • The window shape was being measured from a view underneath the toolbar, so it read short by the toolbar's height.
  • VoiceOver is told when the window changes shape, not only which shape it changed into, and hears the sidebar go.
  • A widget keeps its close, minimise and zoom buttons — hiding a window's toolbar takes those away too.

Under it

  • Seventeen new user-facing strings, all in seven languages. One had to become two: "and 21 more" needs a different word for devices than for networks in Italian, Spanish, French and Portuguese, so a single shared key would have agreed with the wrong noun in four languages while reading perfectly in English.
  • The i18n checker compares placeholders against the English value rather than the key, which is what a namespaced key needs — and so do the three paths that write translations, not only the one that reports.
  • scripts/responsive-interactions.sh drives the single-pane interactions and asserts what came of them. A capture cannot tell you a click did nothing: a window with no detail pane is exactly what a correct list looks like.

Requires macOS 15.6 or later.
