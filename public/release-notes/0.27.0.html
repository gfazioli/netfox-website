Netfox 0.27.0

Release notes

Netfox 0.27.0 puts names on the devices that never gave one, and makes the news of an update smaller: a card that says a new version is here, and a window that holds every release.

Devices

  • Names for devices that announce none. When a device has no name of its own, Netfox now asks it for the one it answers to on your network, the name ending in .local, and most Apple devices, printers and Linux machines reply. It is the name its owner gave it, so a row that read Apple, Inc. now reads Annas MacBook Pro, with the laptop icon, because the name says what the device is. It appears as Local name in the device's details and can be copied: it is an address, so ssh Annas-MacBook-Pro.local works. The search finds it, and it stays while the device is off, for up to 90 days. It is never used to decide that two rows are the same device, and Demo Mode hides it.
  • The Apple logo instead of a question mark. An Apple device whose kind Netfox cannot work out now shows the Apple logo in the list, the detail header and the alerts.

What's New

  • A card, not a panel. After an update, a small card in the corner of the main window says which version is here, and Learn More… opens its notes in the Release Notes window. The notes no longer fill a panel over the window, and the Help menu's What's New item is gone: Help → Release Notes… leads to the same place.
  • Release notes you can browse. Each release in the window shows its first change as a preview, the one you are running is marked Installed, and a dot marks each new release you have not opened yet; it goes the moment you open it. Back and Forward (⌘[ and ⌘]) move through the releases you looked at.

Look and feel

  • Softer Overview cards. The cards are rounder. On macOS 26 and later their glass is clearer, with no line drawn around it and soft violet, teal and rose light behind it, as in the menu bar popover.

Fixes

  • Asking a device for its model can no longer quit Netfox when a send fails.
  • In a rare timing case, asking a device for its model could wait for ever instead of giving up. It now gives up on time.
