Netfox 0.16.4

Release notes

One fix for Local Services, found by a review pass over 0.16.3.

Fixed

Rows stay where you left them. A server listening on the same port at two different addresses — say a web server on both 127.0.0.1:80 and your Mac's own network address — could swap places in the list from one refresh to the next. The order was underspecified, so the two rows were interchangeable and nothing decided between them.

It is more than cosmetic in Demo Mode, where each row's masked name is assigned from its position: two rows swapping meant the same process appeared under a different label.

The order is now fully determined. A row is where you left it.

Under the hood

The list is sorted by port and process name, which leaves two listeners that share both and differ only in reachability incomparable — and Swift's sort is not guaranteed stable, so their relative order was whatever the run produced. The listener's own identity is now the final tiebreaker.

The regression test re-parses the same input fifty times and compares the result. A single pass would not have caught it: the underlying nondeterminism is dictionary iteration order, which stays constant within one run of the app.

Install

Download the DMG, drag Netfox to Applications. Existing installs update themselves.

Requirements

macOS 15.6 or later. Universal (Apple Silicon + Intel). Signed and notarized.
