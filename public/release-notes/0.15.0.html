Netfox 0.15.0

Release notes

This release is about the two questions a network monitor should be able to answer and Netfox couldn't: what settings is this network actually handing out, and how well is each device really reachable.

Your network's settings

A new Network panel on the Overview shows what the network gives to everything on it — the network name, the range of addresses in use, the router, the name servers, the domain, and the device handing out addresses along with how long yours lasts. The things you'd otherwise go digging through a router admin page to find.

If your Mac has been pointed at name servers the network didn't nominate — a manual entry, a VPN, a filtering service — an extra row says so, because the rest of the network is still using what it was given.

On a device's own panel the address now carries the size of the network it sits on (192.168.1.14 /24), and the same lease is available under a collapsed Network context group. It stays folded because it's identical for every device: it belongs to the network, not to the one you're looking at, and Netfox never asks a device what its settings are.

Which device does what

A device that's your Gateway, hands out addresses as the DHCP server, or answers name lookups as a DNS resolver now says so on its own row. On most home networks one box is all three. A name resolver that isn't your router is the interesting case — that's an ad-blocker or a filtering service someone put in the path, and it's worth knowing you have one.

Link quality

Every device now has a Link quality panel: how long a small packet takes to reach it and come back, how steady that is, how often it doesn't answer at all, and a chart of how the day went. Measure now takes a fresh reading on demand; otherwise it fills in on its own, because Netfox was already checking whether each device was reachable and now keeps the timing from those checks.

This is deliberately not the device's Wi-Fi signal strength, and no app on your Mac can show you that — signal is measured by whichever radio is receiving, so only your Apple TV knows how well it hears your access point. What's measured here is the path between your Mac and the device, which is the part you notice when something feels slow.

A sleeping device now says it's sleeping. When the first reply takes far longer than the ones behind it, Netfox tells you that's a device letting its Wi-Fi rest between messages. It's normal for anything battery-powered, and without the explanation it reads as a fault.

Fixes

  • Every explanation in the app now speaks your language. The notes behind each ⓘ were still English on an otherwise fully translated app — all of them are translated now, in all six languages.
  • A device merged with another while Netfox was timing it could lose that measurement from its chart.
  • The Overview's network name is masked in Demo Mode along with everything else, so a screenshot or a screen-share never carries your real network name.
