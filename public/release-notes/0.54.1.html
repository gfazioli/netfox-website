Netfox 0.54.1

Release notes

Netfox 0.54.1 is a small reliability release: This Mac keeps one address when it is on cable and Wi-Fi at once, and scanning can no longer get stuck on a reading that has already finished.

Fixes

  • On a Mac connected by cable and Wi-Fi at the same time, This Mac keeps the address of the connection it actually uses. It used to switch between the two whenever the other connection answered for it, adding an address change to its history each time.
  • Scanning the network is sturdier. Netfox no longer waits for a reading that has already finished to wind down, a wait that could leave scanning stuck until the app was restarted.
