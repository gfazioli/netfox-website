Netfox 0.56.0

Release notes

Netfox 0.56.0 tells you when macOS keeps it off your network, recognises a container's port when it sees one, and lets you say which servers you left running on purpose.

Local Network access

  • When macOS denies Netfox access to your local network, a bar over Devices and Security now says so, with a button that opens Privacy & Security. It goes away by itself as soon as you allow Netfox again, and Netfox scans the network then.
  • While access is off, a port check records nothing instead of marking every port Filtered for a reason that has nothing to do with the device.

Local Services

  • Ports that Colima forwards from its virtual machine are recognised. A row reachable from the network says that the container behind it can be reached by other devices, and how to keep it on this Mac: set the host address of its port mapping to 127.0.0.1.
  • Those rows offer no Quit, because one process carries every port of that virtual machine and quitting it would close them all. Stop the container instead.

Alerts

  • Left a server running on purpose? Say so once, with I meant this one on its alert or under its row in Local Services, and Netfox stops reporting it, even after you restart it on the same port.
  • Local Services marks the servers the alert is timing, so you can answer before it fires.
  • The servers you said so for are listed in Settings → Alerts, each with Report it again. One Netfox never sees for 30 days is dropped from the list.
  • A server started with nohup is still reported, but its alert says it may have been left on purpose.
  • Forget All Devices now forgets these choices too.

Translations

  • The port details (overview, service and raw tabs), the custom port range and a few device details now read in your language; some labels were still in English.

Fixes

  • With the "server left running" alert on, the processes Colima uses to run its virtual machine and forward its ports are no longer reported as servers left behind.
  • The About window no longer opens on top of an app you are using in full screen.
