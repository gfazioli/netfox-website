Netfox 0.3.3

Release notes

Maintenance release: no new features, just making what's already there more accurate, faster, and safer.

Security

  • By Service now separates "exposed" from "at risk". A device serving plain HTTP alongside HTTPS is no longer counted among the genuinely insecure ones. Each service row shows how many of its devices actually carry a finding, and expanding a row badges only those — so the counts always reconcile with the device list.
  • Plaintext admin panels on alternate web ports are now caught. A web interface served without encryption on port 8080 (common on routers and IoT hubs) used to slip through; it's now flagged when there's no secure equivalent.
  • Hardened how other devices' names and banners are displayed. A device on your network can no longer tamper with how its information appears in alerts and notifications.

Privacy

  • Demo Mode now masks the device name in the full history view too, so no real hostname leaks when you share your screen or a screenshot.

Reliability

  • Scans no longer get stuck on slow or unresponsive devices.
  • History is automatically trimmed over time, keeping the app light.

Performance

  • The risk assessment next to each device is now cached, keeping large networks smooth.

Compatibility

  • Fixed the minimum macOS version reported to the updater. Everyone on macOS 15.6 and later now correctly receives updates — if a recent build wasn't offering you the latest version, this resolves it.
